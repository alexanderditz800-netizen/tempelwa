## 📋 Deskripsi
Tempel WA adalah platform yang memungkinkan user menghasilkan uang otomatis dari WhatsApp. Setiap nomor yang terhubung akan menghasilkan **Rp 2.000 per menit** secara otomatis.

## ✨ Fitur Lengkap

### 🌐 Website (User Side)
- ✅ **Registrasi** dengan data bank lengkap
- ✅ **Login** sistem dengan session
- ✅ **Dashboard** dengan statistik real-time
- ✅ **Hubungkan** multiple nomor WhatsApp
- ✅ **Verifikasi** via admin bot Telegram
- ✅ **Penghasilan** otomatis Rp 2.000/menit
- ✅ **WD** (Withdraw) minimal Rp 50.000
- ✅ **Referral** bonus Rp 1.000 per undangan
- ✅ **History** semua aktivitas
- ✅ **Real-time** update via WebSocket

### 🤖 Bot Telegram (Admin Side)
- ✅ **Menu Inline** lengkap
- ✅ **/tambahsaldo** username jumlah
- ✅ **/proseswd** id_wd
- ✅ **/putus** username
- ✅ **/hubungkan** phone code
- ✅ **/status** lihat semua user
- ✅ **Notifikasi** otomatis untuk semua aksi

### 💾 Database
- ✅ Users dengan data bank
- ✅ Multiple numbers per user
- ✅ Pending verifications
- ✅ Withdrawals management
- ✅ History tracking
- ✅ Referral system
